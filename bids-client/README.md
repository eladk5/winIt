# Bids Client

This is the frontend client for the Bids application, built with Next.js.

## Prerequisites

- Node.js 20+
- npm

## Environment Variables

Create a `.env.local` file in `bids-client` with:

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:8080
```

## Installing Dependencies

```bash
npm install
```

## Running the Client

Run the development server:

```bash
npm run dev
```

The client will start on port `3000`.

Open:

[http://localhost:3000](http://localhost:3000)

## Production Build

Build:

```bash
npm run build
```

Start:

```bash
npm run start
```
